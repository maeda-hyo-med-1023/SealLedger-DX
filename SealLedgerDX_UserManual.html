📋 SealLedgerDX 統合自動化システム
取扱説明書（User Manual）

1. システム概要

SealLedgerDX は、校印使用台帳（Excel）の作成・入力作業を効率化するための統合自動化ツールです。

本システムは、以下の5つの主要機能を1つのアプリケーションに統合し、PDF変換・画像加工・ファイル整理・OCR（テキスト化）までをシームレスにサポートします。

  • ✅ Excelフォーマットの複製（ページ追加）
  • ✅ 入力規則の一括セット
  • ✅ PDF → 画像変換
  • ✅ フォルダ一括作成
  • ✅ ファイル振り分け（同名フォルダへ）
  • ✅ 画像カット／リサイズ／Excel挿入
  • ✅ OCR（画像→テキスト化）

💡 本システムは Windows環境 を前提としており、Python 3.10 以上で動作します。

2. 動作環境と事前準備

2.1 必要ライブラリ（インストールコマンド）

pip install openpyxl pillow pdf2image pytesseract

2.2 外部ツール（OCR機能を使用する場合）

  • Tesseract OCR 本体のインストールが必要です。
  • ダウンロード: UB-Mannheim Tesseract
  • インストール時に 「Japanese (jpn)」 言語データを必ず追加してください。
  • デフォルトのインストール先: C:\Program Files\Tesseract-OCR\tesseract.exe

2.3 PDF変換機能を使用する場合

  • poppler が必要です（pdf2imageの依存）。
  • Windowsの場合: poppler Windows版 をダウンロードし、PATHを通してください。

3. 起動方法

コマンドプロンプト（ターミナル）を開き、スクリプトが配置されているディレクトリに移動して、以下のコマンドを実行します。

python SealLedgerDX_Integrated_Green.TLabelframe_v3.py

✅ 起動後、メインウィンドウが表示されます。

4. メイン画面の構成

画面上部には 「表示サイズ」 切替パネル（小・中・大）があり、文字の見やすさを調整できます。

中央には 5つのタブ が配置されています。

① フォーマット＆入力規則 Excel複製・入力規則設定
② PDF変換＆フォルダ作成 画像変換・フォルダ一括作成
③ ファイル振り分け 同名フォルダへの自動格納
④ 校印台帳カット支援 画像カット・リサイズ・Excel挿入
⑤ OCR（画像→テキスト化） 画像からテキスト抽出

5. 各タブの詳細操作

📁 タブ①: フォーマット＆入力規則

  • ①-1 Excelフォーマット複製: テンプレートExcelを選択し、追加ページ数を指定して「複製実行」をクリックすると、_generated.xlsx ファイルが生成されます。
  • ①-2 入力規則を自動セット: マスターExcel（選択肢リスト）と対象Excelを指定し、マスターシート名・列、対象シート名・列・開始行を設定して「入力規則セット」をクリックすると、プルダウンリストが一括適用されます。

📄 タブ②: PDF変換＆フォルダ作成

  • ②-1 PDF → 画像変換: PDFファイルと出力先を指定し、DPI（解像度）とページ範囲（例：1-10、空欄で全ページ）を設定して「変換実行」をクリックすると、page_1.png 形式で画像が出力されます。
  • ②-2 フォルダ一括作成: ベース名（例：page_）と作成数（例：62）を指定し、出力先フォルダを選択して「フォルダ作成」をクリックすると、page_1 ～ page_62 のフォルダが一括作成されます。

🗂️ タブ③: ファイル振り分け

  • ソースフォルダ（画像ファイル）とターゲットフォルダ（格納先）を指定します。
  • ベース名（例：page_）に一致するファイルを抽出し、拡張子を除いたファイル名と同名のフォルダに自動コピーします。
  • 「末尾付与名称」を入力すると、コピー先のファイル名に任意の文字列を追加できます（例：_processed）。
  • 「フォルダ自動作成」にチェックを入れると、対応するフォルダが存在しない場合に自動で作成します。

✂️ タブ④: 校印台帳カット支援（重要機能）

  • 共通設定: Excelファイル（校印使用台帳.xlsx）と画像フォルダを指定し、ページ番号（例：33）を設定します。
  • 「_cutフォルダ作成」「resizeフォルダ作成」ボタンで、出力先フォルダを事前に作成できます。
  • 3つのサブタブ:
    • ① 使途・文書番号: カットのみ（リサイズなし）。page_{n}_cutPurposeDocumentNo.png を出力。
    • ② 日付・使用印 (D列): カット → リサイズ → Excelの D1セル に挿入。page_{n}_cutDate_Stamp.png → page_{n}_resizeDateStamp.png
    • ③ 使用部署・取扱者 (H列): カット → リサイズ → Excelの H1セル に挿入。page_{n}_cutDepartment_User.png → page_{n}_resizeDepartmentUser.png
  • 「次ページへ (+1)」ボタンで、ページ番号をインクリメントしながら連続処理が可能です。
  • ⚠️ Excelファイルに画像を挿入する際は、対象のExcelファイルを閉じてから「D列に挿入」「H列に挿入」ボタンを実行してください。

🔍 タブ⑤: OCR（画像→テキスト化）

  • 画像フォルダと出力先（テキスト保存先）を指定します。
  • ファイルパターン（例：*.png）と言語（例：jpn）を設定します。
  • 「OCR実行」をクリックすると、フォルダ内の全画像がテキスト化され、縦に連結された以下の2つのファイルが出力されます。
    • OCR_result.txt: プレーンテキスト形式
    • OCR_result.md: Markdown形式（見出し付き）
  • 💡 手書き文字の認識精度は、画像のDPIや文字の鮮明さに依存します。必要に応じてタブ②で事前に画像の解像度を調整してください。

6. 便利機能「表示サイズ切替」

画面上部の 「小」「中」「大」 ラジオボタンをクリックするだけで、アプリケーション全体のフォントサイズを動的に変更できます。

  • 👶 小（8pt）：コンパクト表示
  • 👤 中（10pt）：デフォルト（推奨）
  • 👴 大（14pt）：拡大表示（見やすい）

高齢者の方や、解像度の高いモニターを使用する場合に特に便利です。

7. 注意事項

  • Excelファイルを開いたまま実行しないでください。特にタブ④の「挿入」機能は、書き込み権限がないとエラーになります。
  • OCR機能（タブ⑤）を使用するには、Tesseract OCR本体がインストールされ、正しいパス（C:\Program Files\Tesseract-OCR\tesseract.exe）に配置されている必要があります。
  • PDF変換（タブ②）を使用するには、popplerがインストールされている必要があります。
  • 大量の画像を処理する場合は、システムのメモリやCPUリソースに注意してください。
  • 重要なデータは必ずバックアップを取ってから本ツールを実行することを推奨します。

8. よくある質問（FAQ）

  • Q: 「openpyxlがインストールされていません」と表示される。
    A: ターミナルで pip install openpyxl を実行してください。
  • Q: OCRで日本語が正しく認識されない。
    A: Tesseractインストール時に「Japanese (jpn)」言語データが追加されているか確認してください。
  • Q: 画像カット後、画像が変わらない。
    A: カット量（cm）が小さすぎる場合があります。数値を大きくするか、DPI設定を確認してください（デフォルトは96）。
  • Q: 「Excelファイルが開かれています」というエラーが出る。
    A: 対象のExcelファイルを閉じてから、再度「挿入」ボタンを押してください。
